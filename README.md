# 🍔 Prime Grill Hamburgueria

Site institucional da **Prime Grill Hamburgueria**, localizada em Nova Iguaçu - RJ.

## 📋 Sobre o Projeto

Site single-page moderno e responsivo, desenvolvido com HTML5, CSS3 e JavaScript puro (sem frameworks).

## 🎨 Identidade Visual

- **Fundo:** Preto puro `#000000`
- **Cor primária:** Laranja `#FF6600`
- **Tipografia:** Oswald (títulos) + Roboto (corpo)

## 🗂️ Seções

- **Hero** — Apresentação com partículas animadas
- **Destaques** — Hambúrgueres mais pedidos
- **Cardápio** — Combos, Avulsos, Acompanhamentos e Bebidas
- **Como Pedir** — Passo a passo do pedido
- **Sobre Nós** — História da hamburgueria
- **Localização** — Endereço + Google Maps
- **Contato** — Botões de WhatsApp
